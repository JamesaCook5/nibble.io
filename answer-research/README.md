# Answer-bank research records

`verified-expansion-2026-11-27.json` stores the candidates accepted from public APIs, structured datasets, official sources, and reference entries during this research pass. Each accepted item retains the source URL and any interpretation note. The game data and naming differences are scoped in the item notes.

Only item-level or exact dataset evidence was imported. Broad category pages and leads that did not verify a candidate were not treated as evidence. Candidates still under a boundary question are excluded unless the note explains the interpretation.

Rarity values for additions follow the existing Nibble/Byte/Kilobyte scheme; new, uncertain popularity ordering is not presented as measured player success.
